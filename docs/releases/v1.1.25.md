# 1.1.25

发布日期：2026-11-20

这一版主要把「升级」这条路修稳：升级不再把现场调过的流媒体配置改回出厂值，典型症状是「升级完对讲又没声音」「端口莫名其妙变了」。同时修了一批页面问题。

## 修复

- **升级后流媒体配置被重置**：现场在平台页面里调过的公网地址、端口等参数，以前每次升级都会被换回出厂值，而且没有任何提示。原因是这些参数跟着发布目录一起被整个替换了。现在流媒体配置单独存放在持久目录（`config/zlm.ini`），升级只补齐新版本新增的配置项，现场值一个字都不改；从老版本升上来的机器，升级那一次会自动把现有配置搬过去。
- 部署脚本不再把已经填好的 RTC 公网地址覆盖成自动探测出来的值：只有该项为空时才自动填写，页面上设过的地址重启和升级都会保留。
- 部分场景下点播失败：平台内部按固定地址触发的按需点播，会被误判成「没有播放权限」而拒绝，已放行；带授权信息的请求仍按原有校验执行。
- 首页「流媒体运行态」里的会话类型：走加密通道的会话以前会显示成一长串程序内部类型名（`toolkit::SessionWithSSL<...>`），还会压到旁边的会话标识列上，现在显示为「HTTP 会话 · TLS」这类可读文案，完整的原始类型名可以悬停查看。
- 在线用户列表内容过多时不再把页面撑出滚动条，改为表格内部滚动。

## 新增

- 安装与启动时会自动补齐流媒体配置里新增的配置项：从旧版本升上来的机器，不用再手工往配置文件里一条条添加。

## 变更

- 恢复云台操作盘的配色，与其他页面一致，并去掉了一套重复的侧栏样式。
- 多屏播放页面容器简化，设备树与云台面板的背景统一。

## 升级提示

- 升级前请备份 `data/` 与 `config/` 目录。本版起 `config/` 里会多一份 `config/zlm.ini`，它是流媒体配置的真正生效文件，请一并备份。
- 从 1.1.24 升级可用在线升级、增量包或全量包。
- 本次修复了升级重置流媒体配置的问题，建议所有用户升级。
- 如果之前升级已经把公网地址、端口这些值冲掉了，升级本版后需要重新在页面里设一次；设好之后就不会再被升级覆盖。
- Linux、Windows 与容器版按常规方式升级即可，本次没有额外的操作要求。
