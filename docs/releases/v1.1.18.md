# 1.1.18

发布日期：2026-11-09

这次升级的重点是国产化环境：平台现在可以直接跑在人大金仓、阿里 PolarDB 和达梦这三种国产数据库上，
配置里换一行数据库类型即可，不用再改代码。另外录像计划的时段可以直接在时间轴上拖着调，
在线升级的两处硬伤（升级完升级助手消失、换目录升级后服务起不来）也一并修掉了。

## 新增

- 支持人大金仓（KingbaseES）、阿里 PolarDB、达梦（DM8）三种国产化数据库。在配置文件里选数据库类型即可，
  三种库都附带完整的建库脚本与后续升级脚本，装完不需要人工补表。
- 录像计划的时间轴支持拖拽：拖色块中间是整段平移，拖左右两端是改开始/结束时间，自动吸附到 15 分钟刻度。
  点空白处仍然是新增一段，单击色块仍然定位到下面的时间输入框。
- 增量升级包支持 Windows：只下载变化的那部分文件即可升级，不必每次拉整个安装包。
- 随包的 nginx 升级到 1.30.6 稳定版。

## 修复

- 在线升级收尾时会把升级助手自己一起结束掉，导致升级完成后「服务升级」页面一直报「升级助手不可用」，
  必须到机器上手工拉起。已修，升级完成后助手会自动重启并继续可用。
- 把安装包解到新目录升级（旧版本常见的做法）后，服务启动即退出，日志里只留一行「进程授权状态不可用」。
  原因是配置里的授权目录还指向旧安装位置，现在启动时会自动钉到当前安装目录。
- 达梦数据库上发布 OpenAPI 能力时会莫名回滚：库里把文本补齐成定长，比较时多出尾部空格。
  现在比较前两侧都会去掉首尾空白。
- PolarDB 环境下服务启动即失败，已关闭该类型数据库不兼容的客户端预编译。
- 部分 PolarDB 发行版上数据库身份探测直接报错，已改用兼容写法。
- 升级基线上漏了 OpenAPI 的一行安全状态初始数据，新装环境首次打开 OpenAPI 会缺省值。
- 设备管理页头部的「离线」标记原来是灰色，和「在线」的区分度不够，改为红色。
- 「在线用户」页的刷新按钮是灰白底、鼠标悬浮才变蓝，和平台其他刷新按钮不一致，已恢复青绿色。
- 若干页面的「重置」按钮颜色是蓝色，看起来像主操作，统一改成中性灰。
- 报警消息存储开关的说明写的是「默认开启」，实际默认是关闭，容易误判告警管理为什么没有记录。
  提示已按实际口径改正。
- 录像计划时间轴的空白区域点了没反应，现在点空白处可以正常新增时段。

## 变更

- 侧边栏版本徽标点开的升级卡片统一成平台的浮层配色，暗色主题下不再是偏暖的灰色面板。
- 新增的「升级提示」区块统一为琥珀色系，亮色与暗色主题下都清晰可读。

## 升级提示

- 升级前请备份 `data/` 与 `config/` 目录。
- 使用国产数据库时，按 `config/config.example.yml` 里新增的三段示例填写连接信息：
  人大金仓默认端口 54321、PolarDB 3306、达梦 5236。达梦的连接串必须带模式名（schema），
  否则会出现「建表成功但查不到表」。
- 本版新增达梦的全量建库脚本与升级脚本，升级启动时按所选数据库自动执行，无需人工干预。
- 增量升级包现在 Linux 与 Windows 都可用，只包含变化的文件；升级过程会自动备份被覆盖的文件。
- Linux 与 Windows 单机版均可在「服务升级」页在线升级。
