# 1.1.21

发布日期：2026-11-10

这一版集中修 Windows 全新安装和首次配置时遇到的一连串问题，另外让设备在批量上报目录时更稳定。

## 新增

- 本版为安装与稳定性维护版本，无新增功能。

## 修复

- Windows 全新安装后一启动就报「RTP 端口段格式无效」：安装包里的端口配置文件把端口名和数字写成了上下两行，读出来是空值。现在写在同一行，遇到空值也会自动回退出厂默认端口，不会再拒启。
- Windows 端口预检不准：端口被系统临时占用或被系统保留时，以前可能显示「预检通过」，实际服务却绑不上端口。现在能区分「被别的程序占用」「被系统临时连接占用」「被系统保留」三类，分别给出处理建议；检查本身失败时也不再把没检查说成通过。
- 全新安装后在地图左栏「范围」里选中设备，会连续弹出「目录筛选参数错误」：设备被当成目录条件发给后台，五个接口一起报错、每两秒刷一次。现在后台能正确识别设备，范围下拉不再把设备列成筛选项，同一条错误也不会反复弹窗。
- Windows 首次配置引导一完成就报 SIP 启动失败：引导页预填的是另一套平台用的端口 51064，正好落在 Windows 系统保留段里，一定绑不上。现在引导页统一使用正确端口 15564，出包时也会校验，端口串味直接中止出包；服务没真正起来时不再弹「已成功启动」，而是把真实原因显示出来。
- 设备批量上报目录时更稳：先确认消息再入库、批量写入，订阅窗口先保存再发首次通知，减少高并发下的目录丢失和重复处理。

## 变更

- Windows 首次配置引导的默认 SIP 端口改为 15564。已经用旧包完成引导的用户，请在「平台接入配置」里把端口改成 15564 后保存一次。
- 端口预检的结论文案改为显示实际检查的端口数量与端口段，不再把没检查的项目算作通过。

## 升级提示

- 升级前请备份 data/ 与 config/ 目录。
- 建议正在用 1.1.20 Windows 全量包全新安装的用户直接下载 1.1.21 全量包重装；已经装好的机器可以在「服务升级」页在线升级，或用增量升级包。
- 首次配置引导时，请确认 SIP 端口显示为 15564。
- Linux 与容器版不受上述 Windows 问题影响，按常规方式升级即可。
