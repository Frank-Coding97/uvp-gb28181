# 1.1.24

发布日期：2026-11-18

这一版新增了频道视频分享，可以把通道生成链接发给外部人员直接观看；设备告警会在页面右下角实时弹出；Windows 版新增托盘启动器。同时修复了在线升级后平台打不开（403）等问题。

## 新增

- 频道视频分享：把通道生成分享链接发给别人，对方打开网页就能看，不用装客户端、不用登录平台。分享链接可以设置有效期，到期自动失效，也可以随时撤销；撤销或过期不会打断正在观看的人。
- 设备告警实时弹出：设备上报告警时页面右下角会滑出提示卡片，显示告警类型、时间、设备名、通道名以及设备和通道 ID，6 秒自动消失，最多同时显示 4 张，可在服务配置里关闭。
- Windows 托盘启动器：Windows 版新增 UVP-GB28181.exe，双击即可在后台启动服务并在系统托盘常驻，退出时一并停止服务，不用再打开命令行窗口。
- 首页「平台信息」卡片新增部署方式、操作系统、数据库三项，登录后即可看到当前环境信息。

## 修复

- 在线升级后访问平台报 403：升级助手解包时把前端文件权限设成了只有属主可读，而 nginx 以 nobody 身份运行读不到，导致升级完打不开。已修复，升级后前端目录会保持全局可读。**已经升级坏掉的用户需要手动重装一次新版才能恢复**。
- 频道视频分享链接复制成功或失败都没有反馈，现在会给出明确提示。
- 分享链接过期后不再打断正在观看的用户，只对新打开的请求生效；撤销分享也不会影响录像和 SIP 级联。
- 多屏播放全屏时操作栏挡住画面，改为鼠标移到屏幕顶部才滑出。

## 变更

- 多屏播放空窗口配色层次调整，品牌字标退为水印，「待接入」状态更醒目；多屏页外框底色对齐其他页面。
- 统一品牌图标，登录页新增架构动效。

## 升级提示

- 升级前请备份 data/ 与 config/ 目录。
- 从 1.1.23 升级可用在线升级、增量包或全量包。
- 本次修复了升级后 403 问题，建议所有用户升级；已经升级坏掉的用户需要手动重装一次新版才能恢复。
- Linux 与容器版按常规方式升级即可，本次无额外操作要求。
