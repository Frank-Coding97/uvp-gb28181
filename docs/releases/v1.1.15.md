# 1.1.15

发布日期：2026-10-29

本次升级的重点是让 Windows 单机版也能在线升级，并修掉一批只在新机器上才会暴露的启动问题；
另有录像计划、对讲和界面细节的修复。

## 新增

- Windows 单机版支持在线升级：安装后可在「服务升级」页直接换到新版本，不再提示"当前平台不支持"。
  升级过程带容量预检与失败回滚，换版本失败会按快照自动还原到升级前的状态。

## 修复

- Windows 机器首次启动时，录像查询初始化的报错被显示成"端口被占用、监听 IP 不可达"，
  实际是系统缺少时区数据。已把时区数据内置到程序中，新机器不再需要额外环境。
- Windows 上执行在线升级必定失败（同步目录时被系统拒绝），已按平台分开处理。
- 升级换版本后旧进程停不干净：界面提示"已停止"，端口却仍被占用，紧接着重启会卡在端口检查。
  现在按安装目录精确识别进程，并等端口真正释放后再启动。
- 全新部署（MySQL）启动阶段可能失败：数据库里各表排序规则不统一，权限注册联表查询时报错。已统一排序规则。
- 公网 / NAT 环境下对讲连不上或连接很慢：修正了私有地址被当成可达目标的判断，
  并缩短了音频通道的建立等待。
- 录像计划停用后，之前拉起的视频流仍挂在服务器上不释放（重启服务后尤其明显），现在会正确回收。
- 通道列表按在线状态排序，在线设备排在最前。
- 界面细节统一：弹窗与抽屉的"取消"按钮改为平面样式；录像计划删除改用标准警示框（可重试、防重复点击）；
  图像库的批量操作样式对齐；暗色模式下排班表格的选中格对比度提高。

## 变更

- 「国标服务配置」中的「设备接入地址」两项（扫码配网地址、抓拍回传地址）已移除。
  这两个地址现在由平台按实际访问路径自动推导，不需要再手工填写。
  旧配置文件里遗留的这两段会被忽略，不影响启动，建议顺便删除。

## 升级提示

- 升级前请备份 `data/` 与 `config/` 目录。
- Windows 单机版从 1.1.14 及更早版本升级，请先用全量安装包覆盖安装一次；
  装好本版之后，「服务升级」页才能正常使用。
- Linux 版本不受影响，可直接使用在线升级。
