# 1.1.14

发布日期：2026-10-27

本次升级的重点是「能和别人的平台对上」和「装好就能自己升级」：国标级联与 LiveGBS、EasyGBS、WVP 等主流平台做了双向实测对接，把订阅只活一分钟、语音广播没声音、回放十秒必失败这些问题逐条修掉；在线升级从这一版起出厂即可用，不用再手工填更新地址；同时新增一批设备控制接口和 Java 开发包，设备列表也加了一份上手引导。

## 新增

- 在线升级出厂可用：更新地址与发布方签名公钥随程序一起下发，装好打开「检查更新」就能用。自建的更新服务仍可另行配置，两边签名并存、不会互相挤掉。
- 国标级联正式支持与主流平台双向对接：我方作下级可向上级注册、报目录、送实时流、发录像与报警；作上级可接收下级平台注册并下发控制。目录下发时带上云台类型，上级平台里的云台入口不再是「类型未知」。
- 新增 Java 开发包（SDK）与接口契约校验：第三方系统用 Java 接入时不必再手写 HTTP 与签名逻辑，随包附可直接运行的示例。
- 设备操控类接口补充一批：设备与通道的抓图、云台控制、录像与布防等操作都可通过接口调用，并随 OpenAPI 文档给出参数说明。
- 设备列表加入上手引导：首次进入按「列表 / 卡片 / 地图 → 设备 / 通道 → 目录树 → 每行按钮 → 双击穿透」逐步高亮讲解，工具栏上的问号可随时重看。
- 业务分组视图改为按通道展示：该视图的目录树里只有目录和通道，选中目录直接列出通道；离开该视图后自动回到你原来在看的内容。

## 修复

- 修复级联目录订阅「只活一个周期」的问题：回执里补上事件标识，订阅到期后自动重建，不再出现上级平台过一分钟就看不到设备。
- 修复级联语音广播与对讲在部分上级平台完全没声音的问题：兼容对方不同的地址与主题写法。
- 修复级联回放、下载被拒的问题：兼容上级查询里不带文件路径、时间写成零点的写法，录像查询结果不完整时不再整批丢弃。
- 修复级联回放「十秒必失败」：收流等待改为固定上限并可靠清理，暂停中的会话不会被拆掉；点播邀请被拒绝时立即给出对方的原因，不再空等。
- 修复级联控制消息被回 403、停止与暂停拖动失效的问题：会话身份改为按来源地址与平台编码识别，端口变化不再被误判成陌生对端。
- 修复应答与结束消息发到本地地址而非对端真实地址的问题，避免上级平台收不到确认、回放只能等超时。
- 修复下载与更新文件在跳转到内容分发地址时被拒绝的问题，安装包可从官方地址正常下载。
- 修复云录像在上级平台拉流、设备主动推流时不录制的问题：现在只要有流就开始录，不再只认浏览器点播这一个入口。
- 修复媒体节点重启后云端录像被判失败、必须人工重开的问题：节点暂时不可达改为「等待」，恢复后自动继续。
- 修复停播收尾报错被当成「参数错误」返回、导致前端要等十几秒才能重播的问题。
- 修复播放器失败实例被重复使用、以及云台操作报错弹两条的问题。
- 修复手动刷新目录后残留已删除通道、设备树叶子节点看不到通道数的问题。
- 修复下级平台上报 8 位行政区划码、注册不带域信息时整批目录被回滚或注册失败的问题。
- 修复告警被静默丢弃时无任何记录的问题，现在会留下原因和处理方向。
- 修复登录页在手机上一屏放不下、登录按钮看不到的问题。
- 修复首页信令曲线断成几段、定时任务页与录像计划表的多余滚动条等界面问题。

## 变更

- 云录像判定口径调整：媒体节点不可用不再算「录像失败」，通道进入等待状态，节点恢复后自动续录；对账时「媒体已停」视为清理成功。
- 录像查询的时间跨度不再作为拒绝条件，只做常规长度提示。
- 视频流无人观看的回收判断改为读取真实观看人数，避免还在播放时被回收。
- 对讲会话相关数据表补齐接口所需字段与索引，升级启动时自动完成，无需手工执行脚本。

## 升级提示

- 升级前请停止服务，并备份 `data` 与 `config` 目录。
- 从 1.1.13 升级不需要修改配置文件；数据库字段由启动流程自动补齐。
- 在线升级从本版起才内置官方更新地址，1.1.13 及更早版本仍需用安装包升级一次，之后即可在页面里检查更新。
- 若使用过自建的更新服务，原有配置会继续生效，与官方源并存。
- 安装包内置的 ffmpeg 仍为精简版（只保留抓拍与转推用到的编解码），功能与上一版一致。
