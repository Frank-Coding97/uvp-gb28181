# 1.1.13

发布日期：2026-10-22

本次升级把「设备地图」做成了真正能用的找人找点位工具：左栏换成只列有位置的通道树，点位卡片直接起直播、看轨迹、改位置；同时修掉登录后整站打不开、能力授权保存失败、20 位国标编码被抹位、抓拍图归属显示主键等几个现场反馈的问题，并把交付包的流媒体目录浏览从出厂就关掉。

## 新增

- 地图左栏改为「可定位通道树」：只列出设置了位置的通道，按设备分组，点通道直接定位到点位并弹出卡片，点设备一次看全该设备的通道；顶部可按部门或业务分组限定范围，底部提示还有多少通道没设位置。
- 地图点位卡片动作重排：播放视频、查看轨迹、设置位置、通道详情四颗按钮各用一色，一眼分清「播 / 看 / 改 / 跳」。
- 地图上的播放改为贴着地图的小窗，不再整页弹窗；小窗里可以一键进入播放控制台，通道离线时播放按钮直接置灰。
- 「设为默认中心」改为两步操作：先点按钮进入选点状态，在地图上点一下确认位置，再保存。取消或按 Esc 不写任何数据。
- 设备地图支持按时间播放移动轨迹，可看速度与轨迹点，支持一键回到默认中心。
- 媒体节点支持在页面上直接修改 WebRTC 端口，并写回部署端口规划，不用再手工改配置文件。

## 修复

- 修复登录后整站打不开的问题：接口基址结尾多一个斜杠时会拼出 `//api/...`，浏览器把 `api` 当成主机名，页面所有请求失败。现在基址统一去掉结尾斜杠。
- 修复录像查询与回放失败时只弹一串英文报错的问题，改为中文原因提示。
- 修复回放通道参数被当成数字解析、20 位国标编码末位被抹成 0 导致回放找不到通道的问题。
- 修复能力授权保存偶发失败（返回 503）的问题：权限校验移出事务，避免单连接数据库自锁，新建的第三方客户端现在能正常授权。
- 修复抓拍图的设备与通道归属显示成数据库主键的问题，改为按编码与名称双路回退。
- 修复点播首帧判定过早、画面还没到就认为已出图的问题；播放器资源改为按内容版本化，升级后不会再残留旧播放器缓存。
- 修复服务升级页首屏探测失败时反复弹出同一个全局提示的问题。

## 变更

- 交付包内的流媒体服务出厂即关闭目录浏览，并在每次启动时强制保持关闭，避免同网段用户在未登录状态下浏览、下载录像与截图目录。
- 存量环境升级会补齐「固件仓库」菜单与对应权限，此前升级上来的环境该页面会提示找不到。
- 许可证与第三方组件声明整理为根目录的第三方声明文件，README 不再保留上游具体团队署名。

## 升级提示

- 升级前请停止服务，并备份 `data` 与 `config` 目录。
- 从 1.1.12 升级不需要改 `config/config.env`；WebRTC 端口如在页面上改过，会同步写回端口规划文件。
- 地图「设为默认中心」的用法变了：先进入选点、在地图上点位置，再保存。
- 安装包内置的 ffmpeg 仍为精简版（只保留抓拍与转推用到的编解码），功能与上一版一致。
