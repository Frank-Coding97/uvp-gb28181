# 1.1.30

发布日期：2026-11-28

这一版只做一件事：修好 H.265 摄像机在某些电脑上「有画面提示、但播不出来」的问题。

## 修复

- **H.265 摄像机在部分电脑上播放被中断**：当浏览器或电脑的显卡不支持 H.265 硬解码时，播放器会先给出一条「当前环境不支持 H.265」的兼容性提示，然后自动改用软件解码继续播放。以前这条提示被当成了播放失败，播放器随即被销毁，于是用户看到的就是「提示一句就黑屏、重试也一样」。现在这类兼容性提示不再打断播放，只有真正拉不到流、解码确实失败时才会报错。
- **H.265 播放失败后的重试恢复正常**：以前播放失败后播放器实例不会自愈，同一个窗口反复点播放只能一直拿到失败结果，必须刷新整个页面。现在失败会被准确识别并重建播放器，重试即可恢复。

## 变更

- 播放器内部对「兼容性提示」和「最终失败」两类消息做了区分：前者只记录、不中断，后者才提示用户并重建播放器。

## 升级提示

- 这一版只有前端播放器的改动，**没有数据库结构变更**，升级完成后直接启动即可。
- 升级前建议照常备份 `data/` 与 `config/` 目录。
- 如果你的现场全部是 H.264 摄像机、播放一直正常，可以不升级；有 H.265 设备的现场建议升级。
