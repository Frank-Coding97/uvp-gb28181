# 1.1.5

发布日期：2026-10-19

这是 1.1.0 之后的首次对外更新，汇总了级联协同、服务自助升级、HTTPS 配置等能力，
并修复了录像缓存与离线升级中的若干问题。

## 新增

- 级联业务组：可按业务组决定向哪些上级平台共享哪些设备与通道，共享范围调整后即时生效
- 服务自助升级：在系统设置中导入升级包即可完成版本更新，支持查看升级进度、升级记录与版本说明
- HTTPS 管理：系统配置新增 HTTPS 开关，可指定端口并上传证书，保存后平台自动重载生效
- 上级查询设备状态：级联场景下支持按上级平台的请求，查询本级平台及共享设备、通道的在线状态
- 容器化部署：新增 Docker Compose 部署方式，一条命令拉起平台、数据库与流媒体服务

## 修复

- 修复设备录像缓存任务进度回退的问题，进度现在只增不减
- 修复离线升级入口因信任配置缺失而不可用的问题，升级包已内置并保留验签公钥

## 变更

- 图像库卡片底部改为下载、详情图标与分隔线；点击图片可直接预览大图，点击详情在侧边抽屉查看
- 服务升级页面统一为与其他系统页面一致的布局
- 主菜单与系统菜单的顺序整理，图标统一刷新，插件类菜单默认隐藏
- 级联与媒体调度相关页面的交互细节优化

## 升级提示

- 从 1.1.0 升级请先停止服务，备份 data 与 config 目录后再替换程序文件
- 启用 HTTPS 前请准备好证书文件并确认端口未被占用
- 升级完成后建议检查「系统设置 → 服务升级」与「系统配置 → HTTPS」的当前状态
