# 1.1.12

发布日期：2026-10-21

本次升级的重点是「现场不用再猜地址、不用再记端口」：设备接入地址可以在页面上直接配置，绿色安装包的全部端口都能自己改；同时把登录、附件访问、调试接口这一层做了安全加固，并修复了抓拍、录像下载与升级过程中的几个实际问题。

## 新增

- 设备接入地址可配：国标服务配置新增「设备接入地址」，可分别填写扫码配网地址与抓拍回传地址。公网或跨网段部署时，不必再依赖操作员浏览器地址自动推导。
- 所有端口都可修改：绿色安装包解压后，`config/config.env` 直接列出全部 16 个端口（管理页、后端、Redis 与流媒体服务的每一个端口），改完值重启即可生效，不必再记额外的标记写法。
- 首启自动填地址：新装包第一次启动时按本机地址自动生成扫码配网与抓拍回传地址，之后可在页面上改成公网地址。
- 级联目录订阅：可向上级平台发起目录订阅（SUBSCRIBE），并在页面上显示订阅会话状态。
- 信令跟踪增强：报文按业务码分类，会话查询改为按时间窗分组；SIP 日志支持按业务码筛选与合并刷新。
- 媒体节点管理：节点台账显示 mediaid，支持一键复制与搜索；节点弹窗统一「网络地址」的叫法，可回显当前生效值并设置别名。
- 服务升级页面展示离线包上传与服务端处理进度，并防止重复点击应用。
- 设备列表在返回上一页后保留原有的筛选与滚动位置。

## 修复

- 抓拍：设备上报「全部抓拍失败」时，任务不再一直停留在进行中，而是明确显示失败与原因。
- 抓拍回传：上传地址支持配置，nginx 转发时保留带端口的 Host，跨端口部署不再出现「设备回了成功、平台一张图都没有」。
- 录像下载：正在下载的分片不再混进云端录像列表。
- 离线升级包上传不再被 30 秒读超时中断，大包也能正常导入。
- 心跳只刷新已注册的端点，停止播放的信令改走最近验证过的端点，避免设备重新上线后点播失效。
- 绿色安装包：随包内置防火墙代理与 ffmpeg；自签证书补充本机 IP，设备按 IP 直连不再被拒；安装前就检查升级助手目录信任，不再等到最后一步才报英文错误；启动收尾先打印端口规划，再打印访问地址。
- 服务配置去掉「SIP 日志保留天数」，保留期统一在日志清理页设置，避免两处口径打架。

## 优化

- 点播首帧：点播请求发出后提前准备播放器解码器，地址返回即可出画，缩短从点击到看到画面的等待。
- 多屏回放左栏宽度调整，长设备名与多级目录不再撑破容器。

## 变更

- 登录提示统一：账号不存在与口令错误都提示「用户名或密码错误」，不再显示剩余尝试次数；被禁用的账号在口令正确时才提示原因。
- 附件访问：文件详情、下载、改名、删除都按当前用户的数据权限校验；秒传与断点续传只匹配本人上传的文件。
- 跨域与调试接口：跨域响应改为回显具体来源，可配置来源白名单；访问令牌只允许流式订阅与图片类接口用 URL 参数传递；调试页与缓存查看接口默认关闭，且必须登录。
- 列表排序参数只接受「列名 + 升降序」的写法，其他形式一律忽略（不影响正常翻页与排序）。
- 交付包出厂默认值调整：关闭调试模式并自动生成随机签名密钥；报警消息默认不落库、位置历史默认不保存、固定点播地址默认开启。

## 升级提示

- 升级前请停止服务，并备份 `data` 与 `config` 目录。
- 如果之前手工改过 `config/config.env` 里的端口：新版首次启动会逐个提示「旧版生效值 / 本版将改用值」，要保留旧端口就按提示把那一行写回文件再启动一次。
- 抓拍回传地址请填写明文 `http://` 地址（设备不认自签证书）；页面上已配置的地址不会被首次启动的自动填充覆盖。
- 设备按 IP 直连平台时，本次自签证书已包含本机 IP，无需再额外处理证书信任。
