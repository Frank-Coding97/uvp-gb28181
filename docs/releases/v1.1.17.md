# 1.1.17

发布日期：2026-11-04

这次升级把全站界面收拾了一遍：按钮第一次有了统一的配色规则（新增是绿、刷新是青、删除是红、
导出是蓝绿），所有删除确认改成同一种小气泡，并把图像库存取权限拆成了查看、下载、删除三档。
另外补上了几处运维一直在问的能力：定时任务日志一键清理、操作日志能看到接口回了什么、
设备可以用自己的密码参与注册鉴权。

## 新增

- 图像库权限拆成「查看 / 下载 / 删除」三档，可以按人分配。原来只有一档，
  给某人开了图像库就等于让他能删。升级时会按角色现有权限自动补齐，不用手工重配。
- 图像库批量下载改由服务端打包成一个 zip 直接下载，不再逐个文件排队触发浏览器多次弹窗。
- 定时任务日志支持一键清理：可以一次清空当前筛选范围内的执行记录，不必逐条删。
- 操作日志详情现在能看到接口的响应内容（超过 4KB 截断），排查「页面报错了但日志里只有请求」时有用。
- 设备可以配置独立密码参与注册鉴权：不同设备不必再共用一套 SIP 口令。
- 「网络会话」与「媒体观看者」页面支持每 10 秒自动刷新，带倒计时显示，排查会话状态不用手点刷新。
- 设备管理左侧目录栏可以收起，把宽度让给右边的表格；收起再展开时目录展开状态、选中项、
  滚动位置都保留。
- 菜单类型的三个页签补上了类型图标，一眼能分清目录、菜单、按钮。
- 升级助手随平台一起升级，助手的改进不再只惠及新装的机器。

## 修复

- 暗色模式下删除确认气泡是灰底、文字发闷：气泡改用平台统一的浮层底色与描边。
- 删除确认的「确定」按钮原来是普通蓝色，与保存类操作分不清；现在统一是实心红。
- 操作日志详情的「请求参数」永远是空的、「响应数据」从未记录：写操作详情不再丢字段。
- 图像库批量下载接口必然返回 401：下载链接补进免登录白名单后可以正常打包下载。
- 「停用节点」原来点一下就生效，现在会先问一句，避免误停正在承载会话的节点。
- 页面顶部的刷新按钮只有鼠标悬浮时才变青绿，静止时还是白底：页面自己写死的配色副本已清掉。
- 窗口较窄时设备表的操作列被固定住，中间的信息列被压得看不见。
- 首页「信令脉搏」曲线在没有信令时断成两截。
- 系统管理里大量「次级按钮」看着还是默认白底——修掉了 Arco 默认样式盖住平台配色的老问题。
- 空组织、上级平台等表格在窄容器下最后的操作按钮会溢出。
- 自动封禁页去掉了一个点了没用的「调整策略」按钮。
- 安全台账三个页面的筛选改由服务端执行，翻页和统计口径一致。
- 上级平台表的「启用」开关尺寸改回与其他状态列一致。

## 变更

- 全站按钮统一到一套语义配色：新增绿、刷新青、编辑紫、删除红、导出蓝绿、次级浅蓝，
  同一个动作在所有页面一个颜色。按钮尺寸也收敛为三档，原来零散的小尺寸已合并。
- 所有删除确认统一成小气泡：点「删除」在按钮旁弹出，气泡里保留后果说明（如"删除后不可恢复"），
  确定按钮是红色。不再出现有的页面弹居中大窗、有的页面弹气泡。
- 系统管理各页的开关统一为圆形、默认尺寸、行间距 10px。
- 上级平台列表把「上级平台」与「上级地址」合并成一列展示，表格少一列、窄屏不再横向滚动。
- 权限工作台把设备编码与名称合并成一列，说明区默认收起，表格可用宽度更大。
- 「调用记录」「OpenAPI 客户端」等页面顶部只保留一颗刷新，按钮按动作重新分色。

## 升级提示

- 升级前请备份 `data/` 与 `config/` 目录。
- 本版新增两组数据库迁移（图像库存档下载、图像库三档权限）与相应的菜单、接口权限种子数据，
  升级启动时自动执行，无需人工干预。存量角色会按原有接口权限自动补齐，不需要重新配置权限。
- 图像库权限细分后，原先拥有图像库权限的账号默认同时具备查看、下载、删除，行为与升级前一致；
  要收紧时再到角色里逐个改成「只读」或「可下载不可删」。
- 删除确认改成气泡后，删除失败时气泡会关闭，重新点一次「删除」即可重试（权限校验与防重复提交都还在）。
- 设备列表「更多」菜单里的删除、业务目录树右键菜单里的删除仍在弹窗中确认：
  下拉菜单点开就会关闭，气泡没有地方显示。其余入口已全部改为气泡。
- Linux 与 Windows 单机版均可在「服务升级」页在线升级。
