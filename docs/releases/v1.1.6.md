# UVP 1.1.6

发布日期：2026-10-19

- 新增离线包真实上传百分比及已传/总大小，上传完成后明确显示等待服务端受理。
- 新增导入校验三步状态、刷新恢复，以及升级执行五组步骤和断线重连提示。
- 失败展示所在阶段与具体原因，后台处理不使用虚构百分比。
- 修复任务详情抽屉样式，统一系统主题、间距和详情表格，适配长 ID 与窄屏。
- 修复通过内网 HTTP 访问时，因浏览器缺少 randomUUID 而无法创建升级任务的问题。
- 保留 1.1.5 的图像库预览和图标操作，以及验签公钥配置修复。

本包用于 220 的 Linux amd64 绿色包升级验收。导入后仍需手动创建并确认升级任务。
