# 1.1.0

发布日期：2026-10-18

首个对外公开发布的版本。提供 Linux amd64、Linux arm64 与 Windows amd64 三种独立部署包，
解压后按使用手册启动即可，无需预装 Docker、MySQL、Redis 或 nginx。

## 新增

- 支持 GB/T 28181-2016 与 GB/T 28181-2022 设备接入
- 设备管理、通道目录与业务分组管理
- 实时点播、录像查询与回放
- SIP 会话、媒体流与节点健康的分层追踪，便于定位无画面问题
- 多 ZLMediaKit 节点接入与媒体调度
- Linux 与 Windows 独立部署包，自带 Redis 与 SQLite，零预装启动

## 修复

- 首个对外版本，无历史修复记录

## 变更

- 无，首个对外版本

## 升级提示

- 全新安装即可，无需从旧版本迁移
- 下载后请比对官网下载中心给出的 SHA-256 校验值
- 首次启动后请立即修改默认管理员密码
