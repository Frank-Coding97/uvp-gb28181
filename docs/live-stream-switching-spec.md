# 目标

用户可以在通道卡片上配置实时点播的主子码流及设备兼容方式。
参照 WVP 的四组选项，补充设备默认、明确的生效提示及配置校验。
配置保存、新会话使用配置、设备实际输出目标码流是不同结果，界面不得混淆。

本规格建议首期提供通道级播放码流配置，不提供正在播放会话的立即重建。
这一边界待老板审阅确认，不将保存配置宣传为即时切流。

# 当前缺口

- 现有实时点播缺少播放码流配置，不能指定 WVP 支持的四组选流方式。
- 实时点播按通道协调和复用已播放流，再次点击播放不保证新建设备点播会话。
- 通道卡片已有流传输模式等配置入口，可以在相邻位置提供“播放码流”。
- 设备编码参数编辑中的码流选择不代表实时点播选流，二者需要明确区分。

以上为本地源码核对结果，未进行设备抓包或运行时验证。

# 用户故事

- 管理员在通道卡片选择适合设备的播放码流，刷新后配置仍然保留。
- 管理员可以恢复“设备默认”，不必强制指定主码流或子码流。
- 管理员可以识别兼容方式及原始标识，不必猜测同名“主码流”的区别。
- 通道已有直播时，管理员知道配置尚未用于现有会话，不会误以为已经切流。
- 多人观看或录像期间，配置保存不会擅自停止或改变现有直播。

# 首期选项

入口位于通道卡片，“播放码流”使用单个下拉，按兼容方式分组。
主标签采用可读名称，同时提供原始标识作为辅助说明。

| 分组 | 可选项 | 对照 WVP 标识 |
| --- | --- | --- |
| 设备默认 | 不指定码流 | 无 |
| stream 兼容方式 | 主码流 / 子码流 | `stream:0` / `stream:1` |
| 2022（WVP 标注） | 主码流 / 子码流 | `streamnumber:0` / `streamnumber:1` |
| 大华（WVP 标注） | 主码流 / 子码流 | `streamprofile:0` / `streamprofile:1` |
| 水星、TP-LINK（WVP 标注） | 主码流 / 子码流 | `streamMode:MAIN` / `streamMode:SUB` |

共九项；首期子码流范围与 WVP 上述选项一致。
厂商分组是兼容性参考，不保证该品牌全部型号适用，不根据厂商名自动强制选择。
“设备默认”表示由设备决定出流，不等同于已确认的主码流。

# 生效规则

- 配置属于通道，影响该通道后续新建的实时点播会话，所有观看入口遵循同一配置。
- 保存配置不主动停止、重建或修改当前直播，也不停止录像。
- 已有会话被复用时，继续使用该会话原来的请求配置；再次点击播放不等于应用新配置。
- 新建实时会话时使用当时保存的配置；配置与会话开始同时发生时，结果必须能说明
  该次会话使用了哪个配置，不得把后保存的配置冒充为该会话的请求配置。
- “已保存”“本次点播已请求该配置”均不能证明设备实际输出了目标码流。

# 建议验收标准

1. 通道卡片提供以上九项，选中后可识别兼容方式及主子码流，不出现无法区分的同名项。
2. 未配置的通道继续使用设备默认，允许从任意选项恢复默认，原有点播调用继续可用。
3. 保存只作用于目标通道，设备目录同步后仍保留；不会更新其他通道或全表配置。
4. 只有具备相应配置权限的用户能修改；离线通道也可保存供后续点播使用。
5. 保存期间防止重复提交；失败时保留已保存值并展示错误，不显示虚假的保存成功。
6. 保存成功提示“播放码流配置已保存，下次新建直播时使用”；修改已有直播对应配置时，
   卡片明确提示当前直播尚未使用新配置，复用旧会话后也不能将该提示误清除。
7. 新建直播的选流请求与所选值一致，恢复默认后不再主动指定码流；重用现有直播时，
   不把最新保存配置显示为该会话已经使用的配置。
8. 保存不发起直播，不停止现有直播、其他观看者或录像，重复选择当前值不产生额外操作。
9. 配置仅接受上述选项，未知值明确拒绝，不能作为任意自定义协议内容使用。
10. 设备拒绝、点播超时、未出流时沿用明确的播放失败反馈；设备未证明接受目标码流时，
    不显示“已切换主码流/子码流”，不静默改用其他兼容方式或另一种码流并报告成功。
11. 自动化验证覆盖选项、保存与恢复默认、权限、通道隔离、目录同步保留、点播请求、
    会话复用及生效提示；真机验收另行核对请求、设备响应和实际媒体。

# 建议首期非目标

- 播放中的立即切换、自动断流重建，以及为不同观看者或窗口同时维护独立码流。
- 在播放器、多画面、设备卡片、地图气泡另加选流入口。
- 设备级或全量通道批量设置。
- 录像回放和录像下载的码流选择。
- 修改设备编码参数来模拟播放切换。
- 根据网络状况自动调整码流，或自动探测、尝试多种厂商选流方式。
- 扩展上级国标平台选流及外部 OpenAPI 选流功能。
- 远程部署与无关工作区修改。

# 待确认范围

- 老板审阅首期生效边界：配置供新建直播使用，不包含正在播放会话的立即切换。
- 具体真机验收设备尚未指定，不把源码完成或自动化通过当作全部厂家兼容通过。
- WVP 标注“2022”的选项已列入兼容范围；本次未取得正式标准原文，规范定义与约束
  尚需核验，不将 WVP 的界面标注视为标准符合性结论。
