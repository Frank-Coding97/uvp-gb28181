# 国标设备工作台重构需求规格

## 目标

1. 覆盖 GB/T 28181-2016 与 GB/T 28181-2022 的设备控制、配置及完成这些操作所需的查询、应答和通知。
2. 合并当前视频参数与设备配置的重复功能，形成唯一、直接内嵌的配置工作区。
3. 对齐成熟视频管理软件的任务组织方式，降低查找功能、编辑参数和判断执行结果的成本。
4. 全量覆盖指平台提供可用流程，不代表所有设备都支持全部能力，不以按钮存在作为完成证明。

## 用户与用户故事

- 值守人员：围绕当前视频完成云台、预置位、对讲、抓拍等即时操作，无需理解协议名称。
- 设备管理员：在同一工作区读取、修改、应用配置，明确修改对象是设备还是通道、作用于哪一路码流。
- 运维人员：能区分请求发送、设备应答、回读一致和实测结果，遇到超时或部分完成时知道下一步。
- 老设备使用者：2016 设备保留其可用操作，未知能力与明确不支持有不同表现。

## 覆盖范围

以下是产品能力域，不是已经完成原文复核的逐命令全集。完整命令和字段矩阵属于本规格的范围核对附件，进入实现前必须补齐。

| 能力域 | 纳入范围 |
| --- | --- |
| 云台与镜头 | 方向、变倍、聚焦、光圈、停止、预置位、巡航、扫描、辅助开关，以及两版标准定义的相关扩展控制 |
| 定位与守望 | 精准位置控制、状态查询、位置变化订阅通知、看守位、拉框放大缩小 |
| 视频与编码 | 视频参数范围查询、参数属性配置、码流选择、SVAC 编解码配置；读写范围按各版原文核对 |
| 画面配置 | OSD、镜像、隐私遮挡；明确坐标基准与实际作用范围 |
| 录像与存储 | 设备录像启停、录像计划、报警录像参数、存储卡状态和格式化 |
| 报警 | 布防撤防、报警复位、报警上报配置及操作结果所需状态 |
| 基础与维护 | 基本参数、关键帧请求、远程启动、设备软件升级及进度结果 |
| 抓拍 | 抓拍请求、上传和完成反馈、图片结果、部分失败；与浏览器画面截图区分 |
| 音频 | 保留并统一现有广播、对讲流程的能力、权限和执行状态表达 |

范围核对矩阵每项必须记录：版本、条款、规范强度、作用对象、可读/可写/可订阅、现有实现证据、缺口、验收方式。
不能因为是可选项、低频项或当前没有实现而从总范围中删去；设备不支持时如实呈现。
不将国标未定义的曝光、白平衡等厂商私有能力包装为国标功能。

## 产品要求

- 同一个配置项只有一个权威编辑入口；快捷入口定位到同一份编辑内容。
- 配置分组、字段编辑、读取、应用、撤销本地修改均直接内嵌；不再用入口按钮启动另一套配置弹窗。
- 按用户任务组织功能，协议族和标准条款用于技术详情，不要求用户理解它们才能操作。
- 保留视频上下文；复杂配置要有足够编辑空间，不将所有字段强塞入狭窄侧栏。
- 即时控制与持久配置行为明确区分；编辑持久配置不自动下发。
- 明确显示设备、通道、码流以及配置作用范围，不能默默把通道操作升级为整机操作。
- 读取不能无提示覆盖未应用修改；切组、切通道、关闭时保护草稿。
- 应用前可辨认修改项；撤销本地修改不等于设备恢复出厂设置。
- 设备当前值、用户草稿、最近提交值、回读值和媒体实测值分别表达，不混用数据来源。
- 未返回、未知、不支持、离线、无权限、过期、失败分别表达；未知不伪装成关闭或数值零。
- 能力判定综合注册版本、设备反馈及验证记录；不得把低版本或无回包直接等同于不支持。
- 已确认对端不能识别的命令避免正常下发；兼容尝试需单独表达，不普遍放开所有按钮。
- 重启、格式化、升级、可能中断接入的基础参数修改说明影响并确认；普通配置不反复确认。
- 保留现有授权和审计机制，能力可用不等于用户有权操作。
- 不以 SIP/HTTP 成功代替设备执行成功；不支持回读的动作说明证据限制。

## 验收标准

1. 原视频参数与设备配置的重复入口消失，全部配置项有唯一归属。
2. 任一纳入范围的功能可追溯到标准原文和版本；完整矩阵没有未处理的遗漏项。
3. 有合法操作权限的用户能在当前通道上下文找到并执行可用功能，看到状态与结果。
4. 读取、修改、应用、设备拒绝、超时、回读不一致和结果未知均有明确反馈与后续动作。
5. 支持回读的配置以设备回读核对提交结果；适合实测的媒体参数额外验证实际流。
6. 切换分组与通道、刷新、关闭不会静默丢失草稿，也不会将旧设备结果写入新设备视图。
7. OSD/遮挡位置和录像周计划有符合任务的操作方式；保留精确数值和秒级时间输入能力。
8. 桌面常用尺寸与窄窗口无文字遮挡、操作区溢出或不可达按钮；空态与长错误文案保持可读。
9. 实时播放、小窗、云台、探针及独立配置入口的既有有效行为不因重构退化。
10. 测试结果明确区分前端、后端、模拟设备、真实设备；没有真机证据的能力不得标记为真机验收通过。

具体输入与期望输出在 tasks 阶段随任务定义，不另建测试或验收文档。

## 非目标

- 本轮不扩展成国标所有平台业务的重做：注册中心、目录管理、级联、全局报警中心及独立回放系统不整体重构。
- 不引入 ONVIF 或厂商私有配置协议，不把成熟软件的私有功能直接移植为国标能力。
- 不承诺强制让缺少能力的设备执行相应动作，不以模拟结果代替真实设备结果。

## 待确认与后续核对

- 范围建议：覆盖全部上述设备控制相关能力，首批优先完成统一配置工作区，其余缺口分批交付但不从总目标删除。
- 产品载体建议：工作台内提供可扩展的配置编辑空间，保持直接内嵌；具体布局在 plan 阶段结合对标和原型确定。
- 既有缺口文档包含历史快照，当前工作树还有正在进行的设备配置改动，须按当前代码重新盘点，不直接继承旧完成状态。
- 软件升级、SVAC、辅助开关等功能的适用设备、标准约束与验证条件须逐项核对；协议歧义单独列出，不猜测默认行为。
- 本规格待用户确认后进入 plan；本轮不修改业务实现。
