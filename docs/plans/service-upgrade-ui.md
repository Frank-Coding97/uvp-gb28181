---
title: 服务升级页面整理方案
---

老板已要求开始部署 220，本轮按已展示预览和补充的版本说明范围执行。

- 复用现有 Vue 页面和 Arco 组件。顶部版本卡保留升级操作、发布源状态和按需展开的环境信息；记录/自动升级设置分标签，保留现有轮询、权限和二次确认。
- 记录表仅显示紧凑摘要；任务抽屉显示标识、失败阶段及可滚动诊断。版本说明使用独立抽屉，按纯文本安全展示已签名元数据，缺失时明确提示。
- 签名清单的 release_notes/published_at 经离线暂存、重验、任务持久化与公开 DTO 透传；历史任务按原数据兼容，当前版本说明只匹配相同 build 的成功任务，不从运行日志生成。
- 新包嵌入此前新增的菜单迁移，修复旧程序将新迁移账本视为未知记录的版本不一致；不删除迁移记录绕过预检。
- 仅更新 220 install-3 / 52000 实例。使用新 build ID 与 1.1.3 验收版本，先备份、构建校验，再签名升级；不覆盖此前签名制品，不触碰其他实例。
