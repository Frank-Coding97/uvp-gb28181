title: 国标级联订阅展示技术方案
status: locally-verified
spec: ../specs/cascade-subscription-ledger.md
---

1. 在管理平台 DTO 附带只读上级订阅快照，由可选运行时接口提供；复用现有列表/详情及权限，不新增路由。
2. 目录订阅管理器按平台 ID、配置版本、协议配置、有效期与终止原因过滤，短持锁复制 DTO；记录接受、续订、通知完成时间及响应码。会话不持久化。
3. 保留运行时包装链中的只读接口，停止或接口缺失返回不可用，不能伪装成无订阅；其他三类为未接通。
4. 台账增加独立只读组件，四类摘要及目录会话明细；复用已有十秒轮询，刷新失败隐藏旧订阅状态，旧 API 缺字段显示未知。
5. RED 后实现 GREEN，覆盖运行时生命周期、管理 HTTP JSON、Vue 渲染/更新及现有级联回归；执行相关 race、类型检查和差异检查。

风险：这是内存当前状态，没有取消/到期历史；十秒刷新存在可见延迟。通知结果只代表最后一次事务响应，不推导业务端到端交付。
