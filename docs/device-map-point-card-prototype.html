新设计：三条规则

规则怎么落
① 点 = 就地 点一下，卡片锚在这个点上。地图不被盖住 —— 用户点它是为了"边看地图边判断"。
② 动作分两组 看（播放 / 轨迹 / 抓拍）留在地图；管（云台 / 编辑 / 更多）直达目标， 不再经过一个"装所有东西"的抽屉。判据 = 这个动作的结果还需不需要看地图。
③ 播放不抢地图 播放走控制台已有的小窗形态（playback-console.ts 的 minimized）， 不用全屏 modal。小窗可拖、可展开。
④ 抽屉已退役
(2026-09-21 拍板)		 地图这条路径不再进抽屉（切的是 index.vue:994 一行，组件不删 —— 列表视图的「详情」还在用）。代价：地图上查不了通道档案，兜底走「更多 → 在列表中打开」。 ⛔ 不把档案塞进卡片 —— 卡片上限约 300px，展开轨迹已 455px。
⑤ 位置历史未开启时 「轨迹」既不隐藏也不置灰，点了给明确说明： 平台未开启位置历史记录（SIP 服务配置 → 位置历史）。 ⛔ 隐藏/置灰会让用户以为是本通道坏了。

⚠️ 轨迹相关的三条诚实边界（全部来自 220 开发库 145 条真实采样的实测）：

  • 不做速度着色 / 方向箭头 / 高度剖面 —— 设备上报的 speed、direction、 altitude 145/145 全是 0。做了就是伪数据。均速改由平台按"位移 ÷ 间隔"估算， 并且文案必须带「估算」。
  • 不做等距时间轴、不做按真实时长的回放动画 —— 采样间隔实测 0 秒 ~ 18.3 小时（均值 22 分）。 按真实时间回放会在空档里卡住不动。改用按采样序数等步长，时间轴标真实时刻。
  • 断档要看得见 —— 超过 30 分钟的相邻点标琥珀、"这段时间数据不在" 本身是运维要看见的事实（折线在断档处不连）。

✅ 坐标确实在动：实测经度跨度 55.94 m、纬度跨度 113.44 m（≈126 m 对角线）， 所以轨迹线画得出来。但形态是"两个位置之间来回抖动 + 少量远点"，与 GNSS 静止漂移一致 —— 原型里的折线如实画的就是这个形态，不是一条漂亮的巡逻动线。
