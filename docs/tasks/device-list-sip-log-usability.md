## 目标与范围

设备卡片默认9条；在线优先且同状态下稳定排序；从设备穿透到通道后可返回原页码、筛选与目录；切换目录保留设备/通道视角。SIP实时刷新保留可点击数据，增加业务类型筛选，并依据客户现场证据补充分类。保留已上线的NAT修复及其他任务的改动。

老板已授权“直接干”，本次连续执行规格、方案、任务与实现，进度持续报告。

## 方案

默认设备查询采用状态倒序、设备编码与主键升序，保留显式排序。页面独立保存穿透前列表上下文。实时日志在后台合并刷新，限制在途请求，阻止过期结果覆盖，显式查询才显示加载状态。业务类型在会话完整聚合后筛选，统计遵循同一业务条件。仅有协议或唯一事务证据时分类。
