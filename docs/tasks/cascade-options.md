## 已确认范围

新增上级平台补充自动推送目录、录像查询与回放授权、RTCP 保活，均默认关闭。不增加视频编码策略。User-Agent、平台名称、厂商、型号、行政区划、安装地址由所有上级平台共用，维护入口为国标服务配置的国标级联页签。该页签使用国标相关、播放相关相同的表单、保存、重置和响应式布局。

保留目录条数 1/2/4/8/16/32/64，新增默认 1，并发默认 0（不限）；存量配置保留。业务分组维护属于独立会话。

## 实现和验收任务

1. 公共配置加入聚合配置接口和 YAML 保存：验证读取、校验、保存失败回滚、旧客户端省略级联配置时不覆盖已有值；前端验证加载、变更、保存和重置。
2. 三个开关进入平台创建、编辑、查询和数据库升级：验证 SQLite 旧数据升级、新安装默认值、重复迁移，以及四方言脚本配对。
3. 自动目录推送接入平台运行时：首次注册成功推送；普通续注册不重复；注册故障恢复重推；共享版本变化推送；发送失败独立重试；推送不阻塞心跳；停用取消并等待任务退出。
4. 公共元信息进入 SIP 和目录：验证 REGISTER/MESSAGE 的 User-Agent 和配置更新；平台名称不能使用上级平台管理别名；平台目录、行政区划按 2016/2022 版本输出；共享通道反查权限不扩大。
5. 录像查询、回放和控制复用现有服务：验证关闭开关拒绝、未知通道拒绝、共享撤销后不外发、查询分批、Playback SDP、INFO 控制和独立回放会话。
6. RTCP 接入发送器并清理会话：验证 UDP 参数、TCP 不传、65535 端口拒绝、发送器停止后发送上游 BYE 并释放下游资源；查询失败不能误判为停止。
7. 页面验收：核对级联页签与兄弟页签样式、公共信息编辑与重置、新开关回显和完成确认。仅操作未保存草稿，不改真实平台或保存真实配置。

## 验证边界

自动推送采用已有主动目录 MESSAGE 行为，不替代域间 SUBSCRIBE/NOTIFY。RTCP 开关控制 ZLMediaKit UDP RTCP 超时机制，TCP 不适用。源码测试与本地页面验收不等于现场上级平台互通；本任务不包含提交、部署、真实数据库迁移。

## 本轮验证结果

- 前端 5 个定向文件、99 项测试通过；公共配置保存、重置、向导开关和确认信息已覆盖。
- 后端构建通过；级联各包、配置、回放、SDP、MANSRTSP 的竞态检查通过；聚合配置接口和 SQLite 升级/新安装专项通过。
- 目录与 DeviceInfo 集成测试使用临时 SQLite 验证真实共享通道元信息、父节点覆盖和未共享地区隔离；级联录像、回放、RTCP、撤权、并发及崩溃清理专项通过。
- 启动装配测试先复现回放服务引用为空的问题，修正为先初始化回放、再装配级联视频处理器、最后启动上级平台注册；最终级联集成专项与 Go 构建通过。
- 全量检查未通过：controllers 的两项日志上下文测试失败；前端类型检查报固件升级、固件仓库及流媒体表单测试错误，本次级联和服务配置文件未报类型错误。INVITE 竞态检查还发现第三方 SIP 事务计时器与报文头延迟解析并发访问。

- 浏览器实看深色/浅色公共配置、编辑/重置及缩放布局；向导第一步必填和 20 位编码校验已确认。新增开关及完成确认的实屏验收先因锁屏中断、后因用户切换浏览器标签页停止，仍未完成；未保存真实配置或平台。
