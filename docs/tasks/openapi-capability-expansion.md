# 目标

完成已确认的 OpenAPI 设备侧全能力开放范围，包含平台已有设备业务能力及 GB/T 28181-2022 能力。所有任务按 RED→GREEN→REFACTOR 执行：先添加本任务用例并看到失败，再实现，通过后整理代码。

# 执行约束

- 先完成任务 1 的实际能力盘点，再按依赖顺序实施；盘点发现的缺口纳入相应能力任务，不缩减目标范围。
- 保留当前 12 个已公开操作的 scope、路由、签名与响应兼容性。新增 scope 对现有客户端默认禁用。
- adapter 复用领域服务，不调用内部 HTTP controller；每个请求和子资源都重新校验客户端设备/部门范围。
- 不向外开放任意内部路由或原始 SIP/MANSCDP 报文。
- 每个任务所列验证用例均属于该任务的完成标准；设备/媒体验收证据另行记录，不以单测代替。

## 当前进度

- 已建立源能力矩阵：[`openapi-device-capability-matrix.md`](../specs/openapi-device-capability-matrix.md)。矩阵覆盖当前 `device-mgmt` 路由族并区分第三方设备操作、平台管理和上行回调；GB/T 28181-2022 正式文本的逐条核对仍未完成。
- 已建立代码契约注册表，并让当前公开 Gin 路由、bootstrap、兼容目录和契约路由测试引用该注册表；现有对外 scope 未改名。
- 当前契约覆盖代码注册的设备能力，包括配置、告警/状态/位置、事件订阅、设备升级、PTZ、设备录像查询/回放/下载、语音/广播；契约与 adapter 注册一致性由 OpenAPI 集成测试约束。代码注册不等于已发布到数据库 catalog，也不等于设备支持或验收通过。
- 已本地新增 `channel:capabilities`、告警/状态/PTZ 等只读能力，包含部门范围校验、adapter、契约和三态响应；尚未发布 catalog release，也没有线上/真机验收证据。
- 已接入设备配置、维护/升级、录像检索/回放/下载、语音/广播及设备事件的本地 adapter；部分依赖 SIP runtime、master key 或媒体服务才会绑定，依赖缺失时 fail-closed。录像检索已覆盖 2016/2022 profile 选择、响应版本和客户端隔离分页游标；下载目前只创建/读取/取消媒体会话，不承诺文件取回或真实进度。
- 抓拍 adapter 仍未接线：正式数据库迁移与设备可达的固定上传 URL 配置尚缺；不能从 OpenAPI 请求 Host 推导上传地址。
- 设备配置、订阅事件、固件升级、语音/广播、录像下载和部分 PTZ 轨迹能力已有代码契约及运行时接线；平台云录像仍属于平台数据能力，尚未纳入；DeviceInfo 主动刷新缺领域 operation 服务；scope 授权工作台端到端、数据库发布、catalog release、认证 API、模拟器/真机验收仍未完成。
- `go test ./app/openapi/... -count=1` 中其余 OpenAPI 包通过，仅 `TestPostgreSQLInitializationMatchesIntegerFlagModels` 失败；该检查指出现存 `sys_users.must_change_password BOOLEAN` 与 Go 整型模型的 baseline 不一致，与设备能力契约无关，本次未修改该 schema。

# 任务

## 1. 盘点设备操作源能力并固定当前契约

从 device-management 路由、controller、领域 service、GB/T 28181-2022 命令类别及现有 OpenAPI 文档建立逐操作映射。每项标为已对外、已有实现待开放、需补实现、目标设备不支持或平台管理排除，并标注标准版本、风险、设备条件和依赖。

测试用例：

- 输入：当前公开路由、能力 bootstrap、active catalog 测试 fixture 与 OpenAPI YAML。预期：现有 12 个 scope 的 method/path 完全一致，映射结果无重复 scope 或重复 route。
- 输入：device-management 中每个设备侧业务入口及标准设备操作类别。预期：每一项都有明确映射或排除理由；新增一个未分类入口时，清单校验失败。
- 输入：平台管理接口（客户端密钥、固件仓库 CRUD、SIP/媒体配置）。预期：均被标为非设备能力，未加入公开目录。

## 2. 建立唯一的代码能力契约注册表

集中定义 scope、分组、描述、method/path、adapter key/version、resource type、risk、idempotency、协议/标准元数据、确认要求及请求/响应 schema；路由和 bootstrap 使用代码定义，数据库不能创建执行能力。

测试用例：

- 输入：scope 重复、method/path 重复、缺少 adapter、未知 risk/idempotency 的定义。预期：注册或启动校验明确失败，不能发布。
- 输入：合法定义集合。预期：公开 Gin 路由、bootstrap scope、adapter 注册和 active release 候选逐项一致。
- 输入：数据库 catalog 插入一个代码未注册的任意 adapter/path。预期：release 验证拒绝，公开路由仍不生成。

## 3. 扩展统一签名网关请求解析与派发

在共用鉴权、重放防护、速率限制、数据范围、审计和超时链路上支持受限 GET query 与有签名 JSON body 的写操作，并由 release/adapter registry 派发。

测试用例：

- 输入：合法签名的固定长度 application/json POST、有效 scope 和有效 body。预期：adapter 收到已验证的 path/query/body，返回标准 JSON response。
- 输入：同一签名下被修改的 body、错误 Content-Type、未知字段、重复 JSON 字段或 chunked body。预期：请求在业务派发前拒绝，领域 service 调用次数为 0。
- 输入：未授权 scope、过期时间戳、nonce 重放、越权部门设备、active release 无法加载。预期：分别返回既定拒绝/不可用结果，绝不回退到无鉴权 handler。
- 输入：现有 12 项请求的历史签名样例。预期：canonical string 和响应契约不变。

## 4. 建立范围安全的领域 adapter 并接入现有能力

adapter 将外部 DeviceID/ChannelID 解析到内部资源，构造 DepartmentScope，调用领域 service；把资源查询、实时点播和 PTZ 现有专用执行器接入统一派发入口。

测试用例：

- 输入：客户端仅有本部门范围，目标设备属于其部门。预期：adapter 调用领域 service 并返回对应结果。
- 输入：目标设备属于其他部门，或替换成其他设备的 sessionId/operationId/taskId。预期：返回资源不可见，底层控制/读取服务不执行。
- 输入：领域 service 返回设备离线、不支持、超时、数据库错误。预期：映射为明确且稳定的 OpenAPI 错误码，不泄露内部错误详情。
- 输入：当前 6 项设备/通道读取、实时点播和 5 项 PTZ 操作。预期：各自仍走原业务生命周期，quota、operation audit 与数据范围测试通过。

## 5. 发布能力元数据并更新授权工作台

扩展不可变 release snapshot，使工作台从服务端读取描述、协议版本、风险、确认和幂等信息；新增 destructive 风险展示，不再根据 scope 字符串硬编码说明。旧客户端的新增 scope 保持禁用。

测试用例：

- 输入：发布含 GB/T 28181-2022 与 destructive 能力的 release。预期：管理 API 返回对应分组、描述、协议条件、风险和确认要求。
- 输入：已有客户端只授权原 12 项，active release 新增多个 scope。预期：新 scope 均无 grant，调用全部被拒；管理员显式授权后只开放所选 scope。
- 输入：active release snapshot hash、版本或 adapter contract 不匹配。预期：发布/启动 fail closed，不静默改写既有 release。
- 输入：工作台收到未知风险类型和空分组/空目录。预期：未知类型不能显示为“只读”，空状态明确，scope 仍逐项授权。

## 6. 开放设备目录、能力与状态查询

新增盘点认定可开放的设备/通道能力查询、设备信息/状态、控制能力、目录刷新状态、告警读取、存储卡状态、预置位/看守位/巡航轨迹/PTZ 状态等只读操作。

测试用例：

- 输入：客户端可见设备与分页/过滤参数。预期：只返回授权范围内记录，分页总数也只按可见记录计算。
- 输入：不可见 deviceId/channelId 或伪造跨设备通道组合。预期：RESOURCE_NOT_FOUND，不返回所属部门或存在性线索。
- 输入：设备未上报可选状态/存储/预置位数据。预期：按契约返回 unknown/empty 与数据时间，不伪造设备事实。
- 输入：目录刷新被接受但设备尚未应答。预期：返回 operationId 和 pending，不将请求受理表示为刷新完成。

## 7. 开放设备配置读取与设置

接入已实现的视频参数和设备配置读取/刷新/下发能力；按设备协议版本及配置块支持情况执行，写配置要求 scope、审计和幂等策略。

测试用例：

- 输入：GB/T 28181-2016 设备读取其支持的配置块。预期：只发送该版本允许的命令，回包字段按契约返回。
- 输入：GB/T 28181-2022 设备读取 2022 扩展配置，设备能力明确支持。预期：选择 2022 路径并保留 command SN/operation 关联。
- 输入：未知版本、未支持配置块、非法参数、其他部门设备。预期：不发送命令，返回可区分的版本/能力/参数/资源错误。
- 输入：重复 Idempotency-Key 的配置写入。预期：不会重复下发；操作状态可查询且结果语义区分已受理、设备应答和失败。

## 8. 开放云台、镜头与 GB/T 28181-2022 控制

提供方向/变倍/聚焦/光圈、预置位、看守位、巡航、扫描、精准控制/状态、雨刷/辅助控制和目标跟踪等已实现或盘点后纳入的控制。每项操作独立 scope；对无应答的标准命令如实表达结果不可确认。

测试用例：

- 输入：合法方向/速度、预置位、巡航/扫描动作和停止动作。预期：编码出对应 DeviceControl 命令，operation 绑定正确设备/通道，停止命令无持续速度参数。
- 输入：非法速度、预置位编号、巡航轨迹或幂等键缺失。预期：命令发送前拒绝，service 调用次数为 0。
- 输入：2022 目标跟踪控制请求。预期：只返回已下发/结果不可确认；设备应答标记恒为 false，不声称实际跟踪成功。
- 输入：低版本或设备能力不支持的 2022 控制。预期：不会发送高版本命令，返回 CAPABILITY_NOT_SUPPORTED 或对应公开错误。

## 9. 开放报警布撤防与设备录像控制

接入设备报警布防/撤防/复位、报警记录以及设备录像开始/停止等标准设备操作；与平台告警记录删除等管理动作分开。

测试用例：

- 输入：独立授权的布防、撤防、复位和录像启停请求。预期：只下发对应设备命令，scope 与操作审计逐项匹配。
- 输入：缺少控制 scope、越权设备或重复业务幂等键。预期：拒绝越权请求；重复请求不重复改变设备状态。
- 输入：设备无应答或返回 ERROR。预期：分别报告结果未知/设备拒绝，不记录为成功。
- 输入：第三方尝试删除平台历史告警。预期：无对外路由，返回 404/405。

## 10. 开放设备重启、升级与存储卡格式化

提供远程启动/重启、设备软件升级及升级结果、存储卡状态/格式化等维护操作。升级只能引用平台批准且可供目标设备使用的固件版本；仓库上传/管理仍是平台后台功能。破坏性操作需独立 destructive scope 和 confirmed=true。

测试用例：

- 输入：重启/格式化缺少确认字段、confirmed=false、未授权 scope 或其他部门资源。预期：不调用设备服务、不发送 SIP 命令。
- 输入：confirmed=true 且有专属 scope、设备在线及合法存储卡/固件目标。预期：生成可查询 operationId，按设备版本执行并记录审计。
- 输入：固件包不存在、未批准、型号不匹配或版本不支持。预期：下发前拒绝，升级服务调用次数为 0。
- 输入：格式化卡编号未提供、非法编号或重复幂等键。预期：不得把默认值解释成“格式化全部卡”；合法重复请求不重复执行。

## 11. 开放设备录像检索与历史回放

提供按设备/通道、时间段检索录像，创建回放会话及读取/控制/结束会话；回放按协议使用合适的 MANSRTSP 控制流程并受客户端范围约束。

测试用例：

- 输入：合法时间段且设备有多批录像检索响应。预期：按请求 SN 聚合完整列表，过滤跨资源记录并返回稳定分页/游标。
- 输入：起止时间反转、超出允许跨度、设备离线或无录像。预期：分别返回 INVALID_REQUEST、DEVICE_OFFLINE 或空列表；不创建回放会话。
- 输入：创建回放后执行暂停、继续、定位、倍速和停止。预期：动作映射到正确回放会话；跨 client/device sessionId 被拒绝。
- 输入：协议为 2016、2022、未知版本的回放控制。预期：只走设备版本适用的 INFO/MANSRTSP 流程；收到 SIP 200 但无媒体时不报首帧成功。

## 12. 开放录像下载与平台云录像

提供设备录像下载会话创建、状态读取和取消。当前领域服务不提供文件取回或可靠进度，不能在 OpenAPI 声称具备该能力；平台云录像属于平台数据范围，须单独定义后再决定是否开放。

测试用例：

- 输入：授权的设备录像下载请求及有效设备范围。预期：创建当前 client 拥有的 download-mode 媒体会话并返回 sessionId；读取状态与取消均校验 client/device/channel/mode。
- 输入：回放 sessionId、其他 client 的下载 sessionId 或跨设备/通道下载 sessionId。预期：拒绝读取/取消，不暴露资源归属。
- 输入：媒体会话只有 SIP 已发送或待媒体状态。预期：不返回文件 URL、虚构进度或下载成功；真实媒体/文件链路另行验收。
- 输入：平台云录像对象。预期：当前设备下载 API 拒绝把平台存储对象当作设备端录像 ID；平台云录像接口待单独定义。

## 13. 开放图像抓拍与取图

提供设备 SnapShot 会话、结果状态、图像列表与受控内容读取；区分设备新抓拍、平台存量图片和上传令牌。

测试用例：

- 输入：授权抓拍请求，设备返回成功上传。预期：operation/session 与图片资源绑定同一设备/通道，状态在收到图片后才为成功。
- 输入：设备不支持抓拍、上传未完成或超时。预期：明确返回 unsupported/pending/failed，不生成可访问的虚假图片 URL。
- 输入：替换 snapshotId/token 或跨 client 读取内容。预期：返回拒绝，原客户端图片不泄露。
- 输入：图片票据过期或会话取消。预期：内容路由拒绝读取，审计保留资源归属信息。

## 14. 开放语音对讲与广播

提供对讲和广播的独立创建、状态、结束和媒体会话资源。设备协议能力和平台 WHIP/媒体链路状态分别呈现。

测试用例：

- 输入：有对应 scope 且设备/媒体可用的对讲/广播请求。预期：创建隔离的 sessionId，并返回协商所需媒体信息。
- 输入：仅有对讲 scope 的 client 请求广播，或反向请求。预期：CAPABILITY_DENIED，媒体服务不创建 session。
- 输入：跨 client 查询/结束会话、媒体发布授权失效或无读者。预期：不可接入，配额归还且无孤儿授权。
- 输入：会话正常结束/超时/媒体节点故障。预期：状态和审计区分 ended/expired/failed，资源最终释放。

## 15. 开放位置查询与设备事件订阅拉取

开放纳入清单的位置/移动设备查询、事件类型订阅、续订/取消及游标读取。事件结果按 client 数据范围筛选；第一阶段不向客户 URL 推送 webhook。

测试用例：

- 输入：创建告警/状态/位置订阅并从游标读取。预期：仅返回订阅类型和授权设备对应的事件，下一页游标可续读且不重复漏读。
- 输入：非法、未来或过期游标，事件源无稳定历史。预期：返回明确 cursor 错误/重同步结果，不静默返回不完整数据。
- 输入：撤销订阅或 client scope 后继续轮询。预期：后续事件不可见，已授权其他订阅不受影响。
- 输入：GB/T 28181-2022 位置扩展字段及平台未采集字段。预期：已采集字段按版本契约映射，未知字段不编造。

## 16. 补齐文档、迁移与跨层契约闭合

完善 api/openapi-v1.yaml、Java 签名示例和能力工作台描述；需要的新事件存储或 catalog 字段用兼容迁移覆盖 MySQL、PostgreSQL、SQL Server 与 SQLite baseline。不得编辑既有 release 快照。

测试用例：

- 输入：代码定义、公开 Gin routes、active release、管理 API 和 YAML。预期：scope/method/path/request/response/risk/idempotency 一致，遗漏或额外对外路由使测试失败。
- 输入：旧安装库和迁移后但未发布的 catalog。预期：旧 12 项兼容；新目录按既有 bootstrap/release 生命周期发布并 fail closed；历史已发布快照 hash 不变。
- 输入：三种生产支持数据库方言的空库与升级库。预期：迁移、索引、唯一 scope/route 约束和回滚边界符合 schema；SQLite 测试基线同步。
- 输入：更新后的 capability catalog response。预期：前端按服务端数据渲染全部分组，危险项标签、说明、确认要求正确，Vitest 通过。

## 17. 完成协议模拟器与逐型号真实验收

按能力清单形成 2016/2022 与设备型号验收矩阵，区分协议命令、平台应答、设备回执、媒体流和真实动作。只报告实际执行过的设备与环境。

测试用例：
