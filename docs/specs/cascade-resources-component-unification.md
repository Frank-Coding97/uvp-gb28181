# 目标

以账号管理页面为视觉和交互基准，统一共享与目录工作区以及嵌入式通道选择器，消除手写控件与项目组件样式混用。

# 当前事实

账号管理使用项目布局封装 s-fold-page、s-layout-search，树、表格、按钮使用 Arco，并套用 uvp-tree-panel、uvp-list-workspace、uvp-data-table 和 uvp-table-actions 样式。
当前级联工作区的标签、目录树、通道表、复选框及分页主要为手写 DOM；通道选择器也存在原生搜索框、复选框及手写表格。问题来自未使用完整的项目组件及视觉体系。

# 用户故事

- 管理员进入工作区时，看到与账号管理一致的布局、搜索栏、树、表格、按钮、分页和空态。
- 管理员使用目录时，可展开和折叠层级、搜索和选中组织，通过树上方工具栏或节点右键完成目录操作。
- 管理员操作大量通道时，可搜索、分页、跨页勾选并批量操作；选择结果和未保存草稿清晰可见。
- 管理员添加通道时，选择器与主列表具有一致外观，不突然切换为另一套手写控件。

# 验收标准

1. 主工作区和通道选择器复用账号管理的项目布局、控件和表格样式，不保留另画的树行、模拟表格和原生复选框。
2. 共享方式标签采用组件库控件；标签决定草稿方式，保存后生效，切换不丢失目录和绑定。
3. 目录树具有真正的层级展开/折叠及搜索；选中、计数、重名辨识、树上方操作、右键和 Shift+F10 保留。
4. 共享表格与账号管理的表头、行高、边框、勾选、云台权限控件、操作列、空态和分页一致；长编号可辨识且不撑破页面。
5. 搜索、跨页选择、移动、移出组织、取消共享、云台调整和添加共享维持现有草稿语义。
6. 目录共享要求有效共享通道全部归属虚拟组织；模式、资源和目录仍一次保存。
7. 只读和管理权限、非空目录删除限制、确认、保存失败、版本冲突与离开保护保持有效。
8. 继续保持精简页面：不恢复此前移除的标题区、上级状态卡和底部操作栏。
9. 明亮和暗色桌面均与账号管理对照验收；390px 小屏操作可达，不出现整页横向溢出，表格可在自身区域滚动。
10. 行为测试覆盖组件替换后的数据和操作，真实浏览器验证视觉与交互；浏览器验收仅使用可放弃草稿。

# 非目标

不调整后端协议、接口合同、数据库、真实平台配置；不触发上级目录推送；不修改账号管理或全局组件以适配本页面；不新增统一组件抽象或功能。

# 未决问题

无业务规则未决问题。使用账号管理现有组件体系，具体适配及测试安排在方案和任务阶段明确。
