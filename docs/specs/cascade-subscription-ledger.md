## 目标与用户故事

运维人员在每个上级平台的级联台账行，看到上级对本平台的目录、位置、PTZ 精准、告警四类订阅状态，并查看当前有效目录订阅的目标与有效期。

## 验收标准

- 四类始终可见；目录区分已订阅（有效会话数）、未订阅、运行时不可用/状态未知；其余三类如实标记尚未接通。
- 只统计本上级接受成功、未取消、未到期且配置身份仍有效的入站订阅；同类多会话分别展示。
- 明细展示发布目标编码、Event、建立/最近续订/到期时间及最近通知结果，不暴露认证、地址路由或设备源编码。
- 复用台账查看权限及现有十秒刷新；读取失败不继续将旧快照显示为当前已订阅。
- 组件和 API 自动化测试覆盖状态变化、隔离、失效与未知状态，不操作浏览器和现有台账。

## 非目标与执行范围

本次不实现位置/PTZ/告警协议，不新增设备侧订阅，不增加数据库历史和迁移。结束会话消失，进程重启后需要上级重新订阅；已订阅不代表所有通知送达。沿用老板无人值守授权，在本地完成规格、方案、测试与实现，不部署或操作真实上级。
