## 目标

M02 接通上级 SUBSCRIBE 与本级目录变化 NOTIFY。上级只可订阅自己实际获发布的系统、通道、行政区划和业务目录，通知只含发布编码。

## 验收标准

- 初始订阅、同一 dialog 续订、取消和到期具有明确结果；非法来源、目标冲突、错误 Event、旧 CSeq 和错误 tag 被拒绝。
- 初始订阅默认范围内目录在线，立即报告已知离线项；无异常也发送 active NOTIFY 确认订阅，不以主动全量 MESSAGE 代替。
- 当前发布目录新增、元数据变化、删除和上下线分别发送 ADD/UPDATE/DEL/ON/OFF；不由二值在线状态臆造 VLOST/DEFECT。
- NOTIFY 关联原订阅 Call-ID、双方 tag、Event id 和请求 SN，使用递增本地 CSeq；批次串行等待 SIP 200，限制编码后的 UDP 报文大小。
- 发送失败不推进已确认快照；服务端暂时失败有限重试，NOTIFY 超时、408/481 和其他永久拒绝结束订阅。
- 配置变更、停用和删除使旧会话失效；共享变化从新投影计算差分，撤销项仅允许发送原发布 ID 的 DEL，不发送旧元数据。
- 关闭取消并等待所有订阅工作；2016/2022 按平台 profile 编码。

## 边界与授权

限本地源码与隔离测试，不操作浏览器、真实上级、开发级联台账或部署。延续老板“无人值守”“继续推进”的执行授权，不重复请求阶段确认。依据 2022 附录 N / A.2.1.9 及 RFC 6665 核对流程与报文；本机原 PDF 路径不存在，已取公开镜像标准文本复核。2016 按对应技能和现有 profile 编码回归，未重新取得 2016 正式 PDF；双版本真实互操作仍需验收。
