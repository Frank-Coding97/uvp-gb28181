---
title: 移出组织后的保存行为修正规格
status: approved
---

# 目标

消除“移出组织”可以操作、但保存时又要求重新归类的交互冲突。

# 已确认问题

当前目录模式要求全部有效共享通道归入虚拟组织。“移出组织”只解除归属，因此操作后的草稿会被保存规则拒绝。

# 已确认行为：移出后保留共享

- 管理员移出一路或多路通道后，可以直接保存当前目录模式。
- 移出的通道仍与当前上级共享，仅解除组织归属；再次进入页面时保持这一状态。
- 已归类通道和业务目录保持不变；未分组通道按已有普通共享目录关系发布。
- 未分组通道仍能被找到并重新移入组织。

# 验收标准

- 在目录模式将 10 路通道移出组织后保存成功，共享总数不减少，组织内数量变为 0。
- 重新读取后仍为目录模式，组织及其他通道归属不变，移出的通道保持共享且无组织归属。
- 从通道模式切换到目录模式时允许存在未分组通道；仍要求合法业务根。
- 无效目录、重复归属、越权资源和旧版本更新仍被拒绝。
- 取消或保存失败不丢失现有草稿。

# 非目标

不新增取消共享按钮，不自动取消共享，不修改真实设备、既有上级配置或主动推送目录。

# 确认记录

2026-10-15 老板选择“保留共享，允许作为未分组通道保存”，替代原先目录模式必须全量归类的产品约束。
