## 0. 目的与执行规则

### 0.1 目的

对国标级联做**双向全功能验收**，确认本平台与 WVP / LiveGBS / EasyGBS 三家第三方平台的互通性，并把过程中发现的问题按"是否阻断"分流处理，直到问题清单归零。

### 0.2 两个验收方向

| 方向 | 含义 | 本次重点 |
|---|---|---|
| **A 我方作为下级** | 本平台向上级平台注册（SIP REGISTER），上级向我方索取目录、点播、回放、控制 | 主路径，覆盖全功能 |
| **B 我方作为上级** | 第三方平台注册到我方，我方作为上级索取其目录并点播 | 次路径，覆盖接入、目录、媒体、控制、事件 |

### 0.3 问题处理规则（老板明确要求）

1. **阻断类**：导致无法继续后续用例（服务崩溃、注册不上、目录进不去、点播不出图等主干链路断点）→ **立即修复 → 重新部署 → 回测通过后才继续**。
2. **非阻断类**：单点功能异常但主干可继续（某条控制指令无效、某个可选字段缺失、UI 显示问题等）→ **记录到问题清单并跳过**，本阶段跑完后统一修复、部署，再**一次性回测全部非阻断项**。
3. 每条问题必须有：现象、复现步骤、定性（缺陷 / 对端差异 / 设计如此 / 环境问题）、处理结论。
4. 全部问题关闭（修复并回测通过，或定性为"非缺陷"并写明依据）后，本轮验收才算结束。

### 0.4 状态定义

| 状态 | 含义 |
|---|---|
| 待测 | 尚未执行 |
| 通过 | 实际结果符合预期 |
| 失败-阻断 | 失败且阻断后续推进，已按 0.3-1 处理 |
| 失败-非阻断 | 失败但可继续，已登记问题清单 |
| 跳过 | 环境不具备或对端不支持，需注明原因 |
| 阻塞 | 等待外部条件（对端配置、授权、设备） |

## 5. 修复 / 部署 / 回测流程

### 5.1 判定"是否阻断"

满足任一条即视为阻断：
- 服务崩溃、进程退出、端口不再监听；
- 注册或心跳失败（该对端整条链路不可用）；
- 目录无法进入对端（后续媒体与控制的用例都无法执行）；
- 点播 / 回放完全不出图（主干功能不可用）；
- 数据写坏（投影表、共享配置错乱，影响其它对端）。
