# Task 1：后端基础查询限制活跃会话

先增加回归测试并确认失败，再修改查询。

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 默认及显式活跃查询 | 活跃、恰好 5 分钟、超过 5 分钟的会话 | 只返回前两者 |
| 旧空闲参数 | status=idle | 列表为空且总数为零 |
| 已离线及不可用用户 | 近期活动但已撤销、到期、所属用户禁用或删除 | 全部排除 |
| 筛选和分页 | 同账号两个活跃会话及一个空闲会话，pageSize=1 | 每页一条活跃会话，总数始终为二 |
| 重新活动 | 空闲但有效的会话，通过 Authenticate 后 Touch | 登录有效，刷新列表后重新展示 |

# Task 2：前端统一请求活跃会话

先更新页面行为测试并确认失败，再修改页面和接口类型。

| 用例 | 输入 | 期望 |
| --- | --- | --- |
| 筛选入口 | 挂载在线用户页面 | 不存在活跃／空闲状态选择器 |
| 初次查询、搜索、重置和分页 | 原有用户名、部门、IP 条件及页码 | 每次请求固定 status=active，其他条件正确 |
| 自动刷新和可见性切换 | 推进 30 秒、隐藏和恢复页面 | 可见时刷新且固定 active，隐藏时暂停 |
| 强退和请求竞态 | 原有组件回归用例 | 行为继续通过 |

# Task 3：集成验证

- 运行后端在线用户、认证会话、控制器和鉴权相关测试。
- 运行前端在线用户页面、操作组件、API 和心跳相关测试。
- 检查修改文件的格式及 git diff。
- 若现有浏览器已登录，核对页面筛选、请求参数和表格；真实后端是否加载新代码单独记录。

- GREEN：后端 service、controllers、middleware 的在线用户、会话和 JWT 相关测试通过。
- GREEN：前端在线用户页面、强退组件、API 和心跳的 4 个测试文件、16 个测试全部通过。
- 前端修改文件 Prettier 检查和 git diff --check 通过。
- 独立 Chrome / Playwright 使用真实页面组件和模拟接口完成 1440x900、390x844 渲染检查；状态筛选已移除，初次查询、搜索、重置和刷新共 4 次请求全部携带 active，无页面脚本错误。
