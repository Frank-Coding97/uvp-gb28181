# 目标

“在线用户”只展示当前活跃的登录会话，使管理员看到的列表和数量能够反映近期仍在使用系统的用户。

# 用户故事

作为管理员，我希望打开、查询、重置和刷新“在线用户”时，始终只看到活跃会话，避免空闲或已离线会话占据列表。

# 活跃定义

- 沿用现有标准：会话未撤销、未过期，所属用户未删除且已启用，最后活跃时间在最近 5 分钟内（含边界）。
- 请求和可见页面的心跳均可更新最后活跃时间；此处的“活跃”指会话近期有通信，不是必须有鼠标或键盘操作。
- 关闭浏览器、断网或页面隐藏后，若不再有请求或心跳，超过 5 分钟活跃窗口即不再出现在列表中。

# 验收标准

1. 默认查询仅返回活跃会话；列表总数与分页均只统计这些会话。
2. 用户名、部门和 IP 查询，以及重置、翻页、调整每页条数、手动刷新和自动刷新，均不展示空闲会话。
3. 页面不再提供“空闲”筛选入口；列表查询也不能通过状态参数获得空闲会话。
4. 超过 5 分钟没有活动的会话在下一次刷新后消失；恰好 5 分钟的有效会话仍可展示。可见列表继续每 30 秒刷新。
5. 已退出、被强制下线、已过期，或所属用户被禁用、删除的会话均不展示，即使最后活跃时间很近。
6. 空闲但仍有效的会话重新产生合法请求或心跳后，下一次刷新可重新展示。
7. 同一账号的多个活跃登录会话分别展示；强制下线仍只针对选中的会话，且不能强退当前会话。

# 非目标

- 不改变登录有效期、心跳频率或强制下线权限。
- 不因会话空闲而自动退出登录，不删除会话历史。
- 不改为按账号去重，不新增历史会话页面。
- 不把浏览器关闭、断网判定为即时离线。

# 确认结果

- 老板已确认按建议执行：沿用 5 分钟活跃窗口，保留现有登录有效期和自动续期机制。
