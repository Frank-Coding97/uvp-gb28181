    - 标题：`Source` + 右侧计数 `0 / 1`

  - **右栏（Target）**：

### ❌ **错误与状态**
- **空状态**：
  - Target 栏明确显示 `暂无数据`（Arco 默认空态插槽）
  - Source 栏虽有 `0/1`，但实际无数据项（仅一个空 checkbox，疑似数据未加载或过滤导致）
- **潜在逻辑问题**：
  - Source 显示 `0/1` 但无实际可选项 → 可能是“1 个候选”但被过滤/权限隐藏，或数据加载失败
  - Target `0/0` 合理（未授权任何项）
- **无显式错误提示**（如 red error text / toast），但存在 UX 不一致风险

### 🟢 **状态分析（老板反馈：“右侧有大片空白区域”）**
- **问题定位**：
  - Target 栏宽度与 Source 栏等宽，但内容为空 → 视觉上右侧留白过多
  - 穿梭框整体未自适应内容高度（固定高度 or min-height 导致空白）
  - 中间操作按钮垂直居中，但上下留白较大（尤其 Target 区域）
- **根本原因**：
  - 数据未加载完成（Source 本应有 1 项，但渲染异常）
  - 或设计未考虑“空状态时压缩 Target 区域”（Arco `a-transfer` 默认两侧等宽）
  - 缺少“空状态引导”（如“暂无已授权对象，请从左侧选择”）

### ✅ **改进建议（供开发参考）**
1. Source 栏 `0/1` 应对应真实可选项（检查数据源/过滤逻辑）
2. Target 空状态增加引导文案 + 操作建议（如“暂无授权对象，选择左侧项后点击 → 授权”）
3. 调整 `a-transfer` 宽度策略：当 Target 为空时，可缩小其宽度或动态调整比例（如 60%:40%）
4. 操作按钮增加禁用态样式（Source 无选中项时 `>` 灰显 + cursor: not-allowed）
5. 补充搜索 placeholder 提示语
