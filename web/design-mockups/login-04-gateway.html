Design Notes · login-04-gateway

相对现有登录页改了什么

结构与现有 login.vue 一一对应（顶部品牌条 / 左品牌面 / 右表单面 / 页脚）， 不改信息架构与字段，只做三件事：把配色锚回新 logo 的真实取值、 把背景从通用拓扑星图换成产品语义的汇流示意、补齐触感与可达性细节。

#2563EB 品牌蓝 #1D4ED8 按压蓝 #10233F 品牌藏青 #0FAAA6 品牌青 #39D1C7 亮青 #60A5FA 浅蓝
项现状改后理由
主色 #1890ff（Arco 默认蓝） #2563EB / #0FAAA6 新 uvp-mark.svg 用的是 2563EB + 0FAAA6；同屏出现两种蓝会显得"贴牌"。
背景 中心辐射拓扑星图（hub + 8 主星 + 18 副星），中心正压在卡片后面 三路信源 → 接入竖轨 → 单路转发出网，只走页面左右两侧 原图是通用"网络感"，看不出这是什么产品；现图直接复刻 logo 语义，且不再和卡片抢中心。
品牌面识别 只有文字标题 新增 391×112 汇流示意（SIP 信令 / RTP 媒体 / 级联调度 → 网关 → 输出） 把 logo 的抽象线条翻译成架构图，补上"左半分栏为什么存在"的答案。
顶部品牌条 uvp-mark.svg（30px）+ 中文名 + 版本 uvp-wordmark-light.svg（含 UVP 字形）+ 分隔线 + 中文名 + 版本 已有现成的浅色字标资源，用它比"图标 + 纯文字"更完整。
卡片圆角 / 阴影 12px，两层阴影 14px，三层（含 1px 高光描边） 对齐 --uvp-workspace-radius: 14px 与 --uvp-panel-radius: 14px。加密码后按钮也一样。
输入框 46px / 圆角 12px / 边框 #dbe6f4 48px / 圆角 12px / 边框 #d8e3f2，焦点环换成品牌蓝 48px 满足最小点击高度；焦点环从 Arco 蓝改为品牌蓝，和 logo 同色系。
主按钮 letter-spacing: 4px，末字后多出的那份字距使整组视觉偏左 字距只留在两字之间：span{letter-spacing:.3em; margin-right:-.3em} letter-spacing 会在最后一个字后面也加一份；用负 margin 吃掉它，"文字 + 箭头"整组才是真对称。
验证码 裸 <img>，只能鼠标点 加 role="button" / tabindex="0" / aria-label / 焦点环，并补"点击换一张"提示 键盘用户原本无法刷新验证码，是实际的功能缺失。
密码框 无 大写锁定提示做成输入框内嵌胶囊（绝对定位，零行高占用） 登录失败最常见的原因之一。做成内嵌是为了既不顶动下方按钮、也不打乱字段 18px 的间距节奏。
表单底注 无 「建议使用 Chrome / Edge 浏览器访问」+ 状态点 用真实内容占住表单下半区。若不需要可整块删除，卡片高度会回落约 34px。
动效 星点脉冲（已支持 reduced-motion） 轨道报文脉冲 + 汇入点呼吸（同样支持 reduced-motion） 保留原有克制程度，不引入新的大幅位移。
响应式 ≤880px 折单列，品牌面只剩标题 ≤880px 折单列，保留汇流示意（它是识别符号，不该掉）；页脚内边距同步收紧 窄屏丢了 features/chips 没问题，丢了识别符号就变成"随便一个后台登录页"。
网格轨道 —（原实现不是 Grid，没有这个问题） grid-template-columns: minmax(0, 1.05fr) minmax(0, 1fr) + 两项 min-width: 0 实测踩到：1fr 等价于 minmax(auto, 1fr)，auto 最小值会被输入框固有宽度（约 209px）顶大，轨道撑到 375px 而卡片只有 343px，右列内容被裁。窄屏必须显式归零。
